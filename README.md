# 王帅 - AI产品经理个人作品集

一个基于 Tailwind CSS 构建的现代化、响应式产品经理个人作品集网站，展示个人背景、核心能力、项目经验与 AI 实践成果，支持中英文双语切换，全端适配。

## ✨ 项目介绍
这是为求职 AI 产品经理方向打造的专业个人作品集，包含个人简介、技能矩阵、项目案例、AI 实践、数据成果与联系方式，用于简历补充、面试展示、个人品牌沉淀。

## 🛠 技术栈
- 前端：HTML5 + CSS3 + JavaScript
- 样式：Tailwind CSS v3
- 字体：Inter
- 交互：AOS 滚动动画、Chart.js 数据可视化
- 图标：Font Awesome
- 特性：响应式布局、中英文双语、模块化结构、纯静态可直接部署

## 🚀 功能亮点
- 全响应式设计，适配手机/平板/PC
- 中英文一键切换
- 模块化内容结构（关于我 / 技能 / 作品集 / AI项目 / 联系我）
- 项目卡片 + 详情弹窗
- AI 效率提升数据可视化
- 极简高级灰调视觉风格
